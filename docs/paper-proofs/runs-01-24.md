### R01.1 — Three-region remainder bookkeeping
- **Source:** run 01 report.
- **Paper location:** §11.2, the proof of Theorem 11.1 (vertex/edge/face assembly, (11.5)).
- **Statement.** Let L, N_f, N_e, N_v, A_f, A_e, A_v, B, e_f, e_e, e_v be real numbers with |N_f − A_f L²| ≤ e_f, |N_e − (A_e L² + B L)| ≤ e_e and |N_v − A_v L²| ≤ e_v. Then
  |N_f + N_e + N_v − ((A_f + A_e + A_v) L² + B L)| ≤ e_f + e_e + e_v.
  Also, if N = N_f + N_e + N_v and A = A_f + A_e + A_v, then |N − (A L² + B L)| ≤ e_f + e_e + e_v.
- **Proof.** The left-hand quantity is exactly (N_f − A_f L²) + (N_e − A_e L² − B L) + (N_v − A_v L²), by polynomial cancellation. Apply the triangle inequality twice. The second form follows by substituting N and A.
- **Sharpness / examples:** none given.
- **Checks run by the report:** 50,000 random cases in exact `fractions.Fraction` arithmetic, all passed. These are examples, not a proof.
- **Lean status:** Formalized: `SteklovAudit.three_region_remainder` and `SteklovAudit.total_error_from_three_regions` (module `Section11RegionAssembly`, merged).
- **Caveat:** This is pure bookkeeping. It does not establish any of the three local estimates for the Steklov traces, and L is a free real parameter.

### R02.1 — Squared-partition trace identity for a finite-rank spectral projector
- **Source:** run 02 report.
- **Paper location:** §11.2 (squared spatial partition in the proof of Theorem 11.1); ledger item H1 "trace linearity of the squared partition".
- **Statement.** Let P be a finite-rank orthogonal projection, for example P_L = 1_{(−∞,L)}(A) for a self-adjoint A with discrete spectrum. Let χ₁,…,χ_q be bounded self-adjoint operators with Σ_i χ_i² = I. Then
  Σ_i Tr(χ_i P χ_i) = Tr(P), and each Tr(χ_i P χ_i) ≥ 0.
  Commutation χ_i P = P χ_i is not required. More generally, for a finite eigenbasis ψ_j and any real spectral weights w_j, Σ_i Σ_j w_j ⟨ψ_j, χ_i² ψ_j⟩ = Σ_j w_j. The sharp-indicator case w_j = 1[λ_j < L] holds for every real L.
- **Proof.** P is finite rank, so χ_i P χ_i is trace class and cyclicity gives Tr(χ_i P χ_i) = Tr(P χ_i²). Summing over i and using Σ χ_i² = I gives Tr(P). Positivity (filled in): χ_i P χ_i = (P χ_i)*(P χ_i) ≥ 0, so its trace is nonnegative. In the eigenbasis version, write Tr(χ_i P χ_i) = Σ_j w_j ⟨ψ_j, χ_i² ψ_j⟩, exchange the finite sums, and use Σ_i ⟨ψ_j, χ_i² ψ_j⟩ = ‖ψ_j‖² = 1.
- **Sharpness / examples:** none.
- **Checks run by the report:** 200 exact-rational 3×3 cases (Householder orthogonal matrices, two diagonal cutoffs with χ₁² + χ₂² = I), 101 of them with noncommuting cutoff and projector. All passed. These are examples, not a proof.
- **Lean status:** Formalized for diagonal (multiplication) cutoffs in a finite site basis:
  - `SteklovAudit.finite_spectral_trace_squared_partition`, `SteklovAudit.finite_local_spectral_mass_nonneg` and `SteklovAudit.finite_local_count_identity` (module `FiniteSpectralTrace`, merged);
  - `SteklovAudit.PartitionTrace.trace_squared_partition` (SteklovAudit/PartitionTrace.lean), for an arbitrary real matrix P.

  General non-diagonal self-adjoint χ_i are not formalized.
- **Caveat:** This is finite-dimensional or finite-rank only. The infinite-dimensional statement for the DtN operator needs trace-ideal cyclicity, which is not formalized. No spectral-window estimate follows.

### R03.1 — Noncommutative discrete Duhamel identity and contraction bound
- **Source:** run 03 report. The telescoping identity is reused in R04.1 and R15.1.
- **Paper location:** §7.4, (7.24) (the "bounded-quasicommutator Duhamel" step).
- **Statement.** Let R be a (possibly noncommutative) ring and a, b, r ∈ R. Put D = a r − r b, S₀ = 0 and S_{n+1} = S_n b + aⁿ D. Then
  S_n = aⁿ r − r bⁿ = Σ_{k=0}^{n−1} a^{n−1−k} D b^k.
  In particular, if a r = r b then aⁿ r = r bⁿ for every n. In a normed ring with ‖a‖ ≤ 1 and ‖b‖ ≤ 1:
  ‖aⁿ r − r bⁿ‖ ≤ n ‖a r − r b‖.
  For matrices with ‖a‖_op ≤ 1 and ‖b‖_op ≤ 1: ‖aⁿ r − r bⁿ‖_HS ≤ n ‖a r − r b‖_HS.
- **Proof.** Induct on n. The case S₀ = 0 = r − r is immediate. Inductive step: S_{n+1} = (aⁿ r − r bⁿ) b + aⁿ(a r − r b) = aⁿ r b − r b^{n+1} + a^{n+1} r − aⁿ r b = a^{n+1} r − r b^{n+1}. Unrolling the recursion gives the sum form. The norm bound follows from the sum form and submultiplicativity: each term satisfies ‖a^{n−1−k} D b^k‖ ≤ ‖D‖. The HS bound uses the ideal inequality ‖X D Y‖₂ ≤ ‖X‖_op ‖D‖₂ ‖Y‖_op term by term.
- **Sharpness / examples:** none.
- **Checks run by the report:** exact-rational 3×3 contractions built from Householder conjugations. There were 100 trials with 9 powers each (900 checks, all passed); in 64 trials a and b did not commute. These are examples, not a proof.
- **Lean status:** Formalized: `SteklovAudit.polynomial_duhamel_identity`, `SteklovAudit.intertwines_all_powers` and `SteklovAudit.polynomial_duhamel_contraction_bound` (module `Section7PolynomialDuhamel`, merged). These cover the recursive identity and the bound in the ambient norm. The explicit sum form and the HS-ideal version are not formalized.
- **Caveat:** This is a discrete, bounded-operator analogue of the |t| factor. It contains no unitary groups, no unbounded domains, no HS membership of the defect, and no tetrahedral comparison.

### R03.2 — Bounded HS families need not have uniform spectral tails (moving rank-one example)
- **Source:** run 03 report. Repeated in the run 04 note (§2) and in run 06 (report and `SECTION7_UNIFORM_TAIL_AUDIT.md`). Run 07 ran 1,000 further checks. Run 08 refined how it should be read.
- **Paper location:** §7.4, (7.23)–(7.29), and the sentence after (7.29) about normalized annuli; also §7.8.
- **Statement.** On H = ℓ²(ℕ), let P_{≥L} be the orthogonal projection onto span{e_j : j ≥ L}, and let K_n = |e₀⟩⟨e_n| (run 03 uses e₁). Then:
  - ‖K_n‖₂ = 1 for all n;
  - for each fixed n, ‖K_n P_{≥L}‖₂ = 0 once L > n;
  - for every L, sup_n ‖K_n P_{≥L}‖₂ = 1. In particular, ‖K_n P_{≥ n/2}‖₂ = 1 for all n.

  Consequently, pointwise tail decay together with a uniform HS bound does not imply a uniform tail estimate.
- **Proof.** K_n P_{≥L} = |e₀⟩⟨P_{≥L} e_n|, which has HS norm ‖P_{≥L} e_n‖. That is 1 if n ≥ L and 0 if n < L. Take n ≥ L, for example n = 2L ≥ L.
- **Sharpness / examples:** The example itself is the sharpness statement. Run 08 adds a reading: the manuscript claims o(L) only for a fixed chart and only O(L) on changing normalized annuli, so this example contradicts neither claim.
- **Checks run by the report:** run 04 ran 499 exact checks of finite tails together with this example; run 06 ran 11,000 exact checks; run 07 ran 1,000 exact checks of this obstruction. These are examples, not a proof.
- **Lean status:** Scalar fragments only: `SteklovAudit.movingDefect_norm_one`, `SteklovAudit.movingDefect_tail_one`, `SteklovAudit.movingDefect_fixed_tail_zero` and `SteklovAudit.movingDefect_no_uniform_tail` (module `Section7UniformTailObstruction`, merged). These state the coefficient sums, not operators on ℓ².
- **Caveat:** This is an obstruction to one proof shortcut, not a counterexample to (7.29) or to the tetrahedral law. It does not show that the actual normalized gluing defects fail to have uniform tails.

### R04.1 — Truncated-exponential (Taylor) Duhamel identity and HS estimate
- **Source:** run 04 report, and `SECTION7_CONTINUOUS_DUHAMEL_PROOF.md` §3.
- **Paper location:** §7.4, (7.24).
- **Statement.** Let A, B, R be elements of a noncommutative algebra, put D = A R − R B, and let E_N(tA) = Σ_{n=0}^N tⁿ Aⁿ / n!. Then
  E_N(tA) R − R E_N(tB) = Σ_{n=1}^N (tⁿ/n!) Σ_{k=0}^{n−1} A^{n−1−k} D B^k.
  If A, B and R are Hilbert-space operators with ‖A‖_op, ‖B‖_op ≤ M and D ∈ S₂, then
  ‖E_N(tA) R − R E_N(tB)‖_HS ≤ |t| ‖D‖_HS Σ_{m=0}^{N−1} (|t| M)^m / m!.
  Letting N → ∞ gives ‖e^{tA} R − R e^{tB}‖_HS ≤ |t| e^{|t|M} ‖D‖_HS.
- **Proof.** Apply R03.1 to each power: Aⁿ R − R Bⁿ = Σ_k A^{n−1−k} D B^k. Multiply by tⁿ/n! and sum; the n = 0 term vanishes. (filled in) The ideal inequality gives ‖A^{n−1−k} D B^k‖₂ ≤ M^{n−1} ‖D‖₂, so the n-th term is at most (|t|ⁿ/n!) · n M^{n−1} ‖D‖₂ = |t| ‖D‖₂ (|t|M)^{n−1}/(n−1)!. Summing over n = 1,…,N gives the stated bound. The limit N → ∞ follows because E_N(tA) → e^{tA} in operator norm and the HS bound is uniform in N.
- **Sharpness / examples:** The note stresses that this crude exponential majorant is weaker than the unitary |t| bound of R04.4.
- **Checks run by the report:** 1,440 exact identities and norm inequalities on rational matrices, all passed; all 180 generator pairs were noncommuting. These are examples, not a proof.
- **Lean status:** Formalized (identity only): `SteklovAudit.truncated_exp_quasicommutator` and `SteklovAudit.truncated_exp_exact_intertwiner` (module `Section7TaylorDuhamel`, merged). These use rational t and the recursive form of the inner sum. The HS norm estimate is not formalized.
- **Caveat:** This applies to bounded generators only. Taylor polynomials do not substitute for the domain-aware Duhamel argument when the generators are unbounded.

### R04.2 — A fixed HS operator has vanishing spectral tail; the decay is uniform over HS-precompact families
- **Source:** run 04 report, `SECTION7_CONTINUOUS_DUHAMEL_PROOF.md` §2, and the run 06 note `SECTION7_UNIFORM_TAIL_AUDIT.md` (full ε/3-net argument). It was stated without proof in run 03.
- **Paper location:** §7.4, (7.23): "Since ψ(hB) → 0 strongly and F ∈ S₂, finite-rank approximation gives ‖Fψ(hB)‖₂ → 0".
- **Statement.** Let P_L be orthogonal projections on a Hilbert space with P_L → 0 strongly as L → ∞; for example, (filled in) P_L = 1_{[L,∞)}(B) for a self-adjoint B. Then:
  - (a) for every fixed F ∈ S₂, ‖F P_L‖₂ → 0, and likewise ‖P_L F‖₂ → 0;
  - (b) if 𝒦 ⊂ S₂ is precompact in HS norm, then sup_{T∈𝒦} ‖T P_L‖₂ → 0.

  The uniformity in (b) fails for merely HS-bounded families; see R03.2.
- **Proof.**
  - (a) Choose a finite-rank F₀ = Σ_j |u_j⟩⟨v_j| with ‖F − F₀‖₂ < ε. For a rank-one term, ‖ |u⟩⟨v| P_L ‖₂ = ‖u‖ ‖P_L v‖ → 0 by strong convergence. Since ‖P_L‖ ≤ 1, we have ‖(F − F₀) P_L‖₂ ≤ ε uniformly in L. Hence limsup ‖F P_L‖₂ ≤ ε for every ε. (filled in) For left multiplication, ‖P_L F‖₂ = ‖F* P_L‖₂ and F* ∈ S₂.
  - (b) Given ε, take a finite ε/3-net T₁,…,T_m of 𝒦 in HS norm. By (a), there is L₀ with ‖T_i P_L‖₂ ≤ ε/3 for all i and all L ≥ L₀. For any T ∈ 𝒦 pick T_i with ‖T − T_i‖₂ ≤ ε/3; then ‖T P_L‖₂ ≤ ‖T − T_i‖₂ + ‖T_i P_L‖₂ ≤ 2ε/3.
- **Sharpness / examples:** R03.2 shows that boundedness alone does not suffice.
- **Checks run by the report:** included in the 499 checks of run 04 and the 11,000 checks of run 06, which were finite-coordinate tails only. These are examples, not a proof.
- **Lean status:** Scalar fragments only: `SteklovAudit.finite_hs_tail_le_total` and `SteklovAudit.finite_hs_tail_vanishes` (module `Section7HSTails`, merged). These cover finite-coordinate tails only; strong convergence and precompactness are not formalized.
- **Caveat:** The result gives no rate. It does not show that the tetrahedral defect family is precompact, and it does not show ε(h) → 0 in (7.23) for the actual operators.

### R04.3 — Finite relative spectral primitive: ∫(N_A − N_B) μ⁻² dμ = Σ 1/a_j − Σ 1/b_k
- **Source:** run 04 report and `SECTION7_RELATIVE_PRIMITIVE_AUDIT.md`.
- **Paper location:** §7.7, (7.38)–(7.45) (relative wedge primitive and negative-energy normalization).
- **Statement.** Let a_1,…,a_m > 0 and b_1,…,b_n > 0 be finite multisets, with N_A(μ) = #{j : a_j ≤ μ} and N_B(μ) = #{k : b_k ≤ μ}. Then
  ∫_0^∞ (N_A(μ) − N_B(μ)) μ⁻² dμ = Σ_j 1/a_j − Σ_k 1/b_k.
  The integrand vanishes below min(a, b), and the integral converges at ∞ even when m ≠ n.
- **Proof.** For a > 0, ∫_0^∞ 1[a ≤ μ] μ⁻² dμ = ∫_a^∞ μ⁻² dμ = 1/a. Write N_A and N_B as finite sums of such indicators and use linearity. (filled in) Each indicator integral is finite, so the difference integral converges absolutely.
- **Sharpness / examples:** none.
- **Checks run by the report:** 700 randomized exact-rational tests, integrating exactly piece by piece between sorted breakpoints. All passed. These are examples, not a proof.
- **Lean status:** Scalar fragments only: `SteklovAudit.finite_relative_inverse_trace` (Σ a_i⁻¹ − Σ b_i⁻¹ = Σ (a_i⁻¹ − b_i⁻¹) over a common index set) and `SteklovAudit.finite_spectral_count_below_bottom` (module `Section7RelativeFinite`, merged). The integral identity is not formalized.
- **Caveat:** The massive wedge has continuous spectrum. This identity does not license writing Tr(1_{(−∞,μ]}(A) − 1_{(−∞,μ]}(B)) as an ordinary trace, nor exchanging the relative trace with the μ⁻² integral. The continuum spectral-shift construction and normalization in (7.38)–(7.45) remain unverified.

### R04.4 — Continuous-time Hilbert–Schmidt Duhamel lemma for unbounded self-adjoint generators, with a localized corollary
- **Source:** run 04 report and `SECTION7_CONTINUOUS_DUHAMEL_PROOF.md` §1. Repeated in run 14 (with a remark on S₂-measurability). A bounded-operator version with the opposite orientation and its own proof is R21.1.
- **Paper location:** §7.4, (7.23)–(7.24).
- **Statement.** Let A and B be self-adjoint, possibly unbounded, on H_A and H_B. Let J : H_B → H_A be bounded with J Dom(B) ⊆ Dom(A), and suppose A J − J B, defined on Dom(B), extends to K ∈ S₂(H_B, H_A). Then for all real t:
  e^{−itA} J − J e^{−itB} = −i ∫_0^t e^{−i(t−s)A} K e^{−isB} ds, and ‖e^{−itA} J − J e^{−itB}‖₂ ≤ |t| ‖K‖₂.
  Localized form: let Z_h : H_0 → H_B be HS and suppose sup_{|s|≤S} ‖K e^{−isB} Z_h‖₂ ≤ ε(h). Then ‖(e^{−itA} J − J e^{−itB}) Z_h‖₂ ≤ |t| ε(h) for |t| ≤ S.
- **Proof.**
  1. For u ∈ Dom(B), set f(s) = e^{−i(t−s)A} J e^{−isB} u. By the domain hypothesis f is differentiable with f′(s) = i e^{−i(t−s)A} K e^{−isB} u. (filled in) In the difference quotient, the term with the increment of e^{−isB}u tends to e^{−i(t−s)A} J(−iB) e^{−isB} u, using the uniform bound on the unitary group and e^{−isB}u ∈ Dom(B). The term with the increment of e^{−i(t−s)A} acts on J e^{−isB} u ∈ Dom(A) and tends to i A e^{−i(t−s)A} J e^{−isB} u. A commutes with its group on Dom(A), and the sum is i e^{−i(t−s)A}(A J − J B) e^{−isB} u. f′ is continuous because K is bounded.
  2. The fundamental theorem of calculus gives f(t) − f(0) = J e^{−itB} u − e^{−itA} J u = i ∫_0^t f′. This is the identity on Dom(B). Both sides are bounded operators, so it extends to H_B by density.
  3. HS integral, (filled in; addresses the run 14 measurability remark): for K ∈ S₂, the map s ↦ e^{−i(t−s)A} K e^{−isB} is continuous into S₂. It is continuous for rank-one K = |x⟩⟨y|, since the map becomes |e^{−i(t−s)A} x⟩⟨e^{isB} y|, and it is uniformly approximable by finite rank. So the integral exists as an S₂-valued Riemann/Bochner integral and agrees with the strong integral. Unitary invariance of the HS norm and the integral triangle inequality give the |t| ‖K‖₂ bound.
  4. Localized form: multiply the identity on the right by Z_h, then use the same triangle inequality and unitary invariance on the left factor.
- **Sharpness / examples:** none given.
- **Checks run by the report:** none specific; it is a functional-analytic proof.
- **Lean status:** Not formalized as stated (unbounded operators, unitary groups, Bochner integral). The finite-dimensional eigenbasis analogue ∑_{ij} |(e^{ita_i} − e^{itb_j}) J_ij|² ≤ t² ‖K‖²_HS is compiled as `SteklovAudit.AbstractTransfer.duhamel_hs` (SteklovAudit/AbstractTransferB2.lean).
- **Caveat:** The lemma is conditional. The hypotheses J Dom(B) ⊆ Dom(A), the HS extension of AJ − JB, and the localized ε(h) → 0 are not verified for the tetrahedral DtN operator and its wedge or half-space model. Those are exactly the open inputs of (7.23).

### R05.1 — Noncommutative off-band Neumann series for (7.46), with uniform bounds on normalized annuli
- **Source:** run 05 report and `SECTION7_OFFBAND_AND_DYADIC_AUDIT.md` §A.
- **Paper location:** §7.8, (7.46), and the equation (5.10) it solves.
- **Statement.**
  - **Abstract part.** Let T ∈ B(H_A), S ∈ B(H_B) and U ∈ S₂(H_B, H_A), with q := ‖T‖ ‖S‖ < 1. The equation X = T X S − U S has a unique solution in S₂, namely X = −Σ_{k≥0} T^k U S^{k+1}. The partial sums X_N = −Σ_{k<N} T^k U S^{k+1} satisfy:
    - X_N − T X_N S + U S = T^N U S^{N+1};
    - X − X_N = T^N X S^N;
    - ‖X‖₂ ≤ ‖U‖₂ ‖S‖ / (1 − q) and ‖X − X_N‖₂ ≤ q^N ‖U‖₂ ‖S‖ / (1 − q).
  - **Application.** Take T = (A − L)E, U = EK and S = (B − L)⁻¹(1 − Q), where E = 1_{[L−w,L+w]}(A) and Q = 1_{[L/2,2L]}(B). If ‖EK‖₂ ≤ C(1 + L), L > 4w and L ≥ 1, then ‖X‖₂ ≤ 8C and ‖X − X_N‖₂ ≤ 8C(2w/L)^N.
- **Proof.**
  - Φ(Y) = T Y S has norm at most q on S₂, so the Neumann series converges absolutely in S₂, and uniqueness follows from ‖X − Y‖₂ ≤ q ‖X − Y‖₂.
  - (filled in) Residual: T X_N S = −Σ_{k=1}^{N} T^k U S^{k+1}, so X_N − T X_N S = −U S + T^N U S^{N+1}.
  - Tail: X − X_N = −Σ_{k≥N} T^k U S^{k+1} = T^N(−Σ_{k≥0} T^k U S^{k+1}) S^N = T^N X S^N.
  - Norms: ‖T^k U S^{k+1}‖₂ ≤ q^k ‖U‖₂ ‖S‖. Summing the geometric series gives the first bound, and ‖T^N X S^N‖₂ ≤ q^N ‖X‖₂ gives the second.
  - Application: ‖T‖ ≤ w because E restricts A to [L−w, L+w]. (filled in) ‖S‖ ≤ 2/L because off [L/2, 2L] we have |b − L| ≥ L/2. Hence q ≤ 2w/L < 1/2 and ‖X‖₂ ≤ C(1+L)(2/L)/(1/2) = 4C(1+L)/L ≤ 8C for L ≥ 1. The truncation bound follows the same way.
  - (filled in) Origin of the equation: with X = EJ(1−Q), the Sylvester relation (A−L)E X − X(B−L) = EK(1−Q), multiplied on the right by (B−L)⁻¹(1−Q), gives X = T X S − U S. This uses the domain identities the note assumes.
- **Sharpness / examples:** none.
- **Checks run by the report:** 120 noncommuting fixed-point solves, 1,080 iterate-error identities, 1,080 residual identities and 1,200 squared-HS bounds. All were exact, in dimensions 2 and 3, and all passed. These are examples, not a proof.
- **Lean status:** Scalar fragments only.
  - The ring identities X − X_n = Tⁿ X Sⁿ are compiled as `SteklovAudit.offBandStep_difference`, `SteklovAudit.offBandIterate_increment` and `SteklovAudit.offBandIterate_error` (module `Section7OffBandIteration`, merged).
  - The scalar geometric bound (2/L)·Σ(2w/L)ⁿ·C(1+L+w) ≤ 12C is compiled as `SteklovAudit.UniformHS71.collar_geometric_bound` (SteklovAudit/UniformHS71.lean).
  - The HS convergence and uniqueness are not formalized.
- **Caveat:** Everything is conditional on the uniform normalized-annulus bound ‖EK‖₂ ≤ C(1+L) (the uniform form of (7.2)) and on the operator-domain identities. Neither is established for the tetrahedron.

### R05.2 — Dyadic exterior primitive: summability, L¹ bound and Riemann–Lebesgue decay
- **Source:** run 05 report and `SECTION7_OFFBAND_AND_DYADIC_AUDIT.md` §B. Run 14 repeats the finite identity Σ_{j<N} 4^{−j} = (4/3)(1 − 4^{−N}).
- **Paper location:** §7.7, (7.42)–(7.43).
- **Statement.** Let R_j = 2^j R_0. Suppose that for |t| ≤ S, F_j(it)/(it) = R_j⁻² G_j(it/R_j) with sup_j |G_j| ≤ C, extended continuously at t = 0. Then:
  - Σ_{j≥0} R_j⁻² = (4/3) R_0⁻²;
  - H(t) = Σ_j F_j(it)/(it) is continuous on [−S, S] with |H| ≤ 4C/(3R_0²);
  - for κ ∈ C_c^∞, ‖κ(·/S) H‖_{L¹} ≤ (4CS/(3R_0²)) ‖κ‖_{L¹};
  - ∫ e^{itL} κ(t/S) H(t) dt → 0 as L → +∞.
- **Proof.** Σ 4^{−j} = 4/3; (filled in) the finite form Σ_{j<N} 4^{−j} = (4/3)(1 − 4^{−N}). The Weierstrass M-test with majorants C R_j⁻² gives uniform convergence of continuous functions, so H is continuous and bounded. The L¹ bound is sup|H| · ∫|κ(t/S)| dt = sup|H| · S ‖κ‖₁. The Riemann–Lebesgue lemma gives the decay.
- **Sharpness / examples:** none.

### R18.1 — Continuous-density Tauberian obstruction: a two-term heat expansion does not give a sharp two-term count
- **Source:** run 18 report.
- **Paper location:** §11 (unsmoothing); the manuscript itself says it avoids a heat-to-sharp Tauberian inference (§11.1).
- **Statement.** Let ρ(x) = 2x + 1 + x sin x for x ≥ 0. Then:
  - ρ(x) ≥ x + 1 > 0;
  - N(L) = ∫_0^L ρ = L² + L + sin L − L cos L;
  - for t > 0, H(t) = ∫_0^∞ e^{−tx} ρ(x) dx = 2/t² + 1/t + 2t/(1 + t²)², so H(t) = 2t⁻² + t⁻¹ + O(t) as t → 0⁺;
  - however (N(L) − L² − L)/L = sin L / L − cos L has liminf −1 and limsup +1.

  So no N(L) = L² + L + o(L) law holds.
- **Proof.**
  - x sin x ≥ −x for x ≥ 0, which gives the lower bound on ρ.
  - ∫_0^L x sin x dx = sin L − L cos L.
  - ∫_0^∞ e^{−tx} 2x dx = 2/t² and ∫_0^∞ e^{−tx} dx = 1/t. Also ∫_0^∞ x e^{−tx} sin x dx = −(d/dt)(1/(1 + t²)) = 2t/(1 + t²)², by differentiating ∫ e^{−tx} sin x dx = 1/(1 + t²).
  - (filled in) Along L = 2πk + π, cos L = −1 and the ratio tends to +1. Along L = 2πk it tends to −1.
- **Sharpness / examples:** (filled in) 2t/(1 + t²)² = 2t + O(t³), so H(t) even has a complete expansion 2t⁻² + t⁻¹ + 2t + O(t³). This makes the point stronger.
- **Checks run by the report:** 10,000 exact rational checks of the Laplace correction bound 2t/(1 + t²)² ≤ 2t. These are examples; the integrals and limits above are proved analytically.
- **Lean status:** Scalar fragments only: `SteklovAudit.Section11LaplaceObstruction.denominator_pos`, `SteklovAudit.Section11LaplaceObstruction.correction_nonneg` and `SteklovAudit.Section11LaplaceObstruction.correction_le_two_t`.
- **Caveat:**
  - The measure is absolutely continuous, not a discrete spectrum; R19.1 gives a discrete version.
  - It refutes a general real-variable implication. It is not evidence against the tetrahedral claim, which does not rely on heat asymptotics alone.

### R19.1 — Discrete positive-spectrum Tauberian obstruction with a three-term heat expansion
- **Source:** run 19 report.
- **Paper location:** §11 (unsmoothing), general.
- **Statement.** Place eigenvalue n ∈ {1, 2, …} with multiplicity a_n = 2n + 1 + (−1)ⁿ n, i.e. 3n + 1 for even n and n + 1 for odd n (all positive). Then:
  - N(m) = Σ_{n=1}^m a_n = m² + 2m + Σ_{n=1}^m (−1)ⁿ n, where the alternating sum is k at m = 2k and −(k + 1) at m = 2k + 1;
  - (N(m) − m² − 2m)/m tends to +1/2 along even m and −1/2 along odd m, so there is no constant b with N(L) = L² + b L + o(L);
  - with q = e^{−t}, H(t) = Σ a_n qⁿ = 2q/(1 − q)² + q/(1 − q) − q/(1 + q)² = 2t⁻² + t⁻¹ − 11/12 + O(t) as t → 0⁺.
- **Proof.**
  - Σ (2n + 1) = m(m + 1) + m = m² + 2m. Pair consecutive terms of the alternating sum.
  - (filled in) N(m)/m² → 1, so the leading coefficient must be 1. Then b would equal 5/2 along even m and 3/2 along odd m, a contradiction.

- **Sharpness / examples:** This is integer-valued, monotone, pure point, with positive multiplicities.
- **Checks run by the report:** 5,000 integer cumulative-count identities and 5,000 rational generating-function identities, all passed. These do not test the asymptotic expansions.
- **Lean status:** Scalar fragments only: `SteklovAudit.Section11DiscreteHeatObstruction.multiplicity_positive`, `.multiplicity_even`, `.multiplicity_odd` and `.pair_multiplicity`.

### R20.1 — Unit-window local mass bound implies a sharp-versus-smoothed estimate
- **Source:** run 20 report.
- **Paper location:** §11.1, (11.1)–(11.2), and §7.8 ("all normalized local windows satisfy C(VL + 1) … Summing unit windows and integrating against the fixed Schwartz kernel").
- **Statement.** Let μ be a nonnegative locally finite measure on [0, ∞) and N(L) = μ([0, L]), with N = 0 for L < 0. Suppose that for all integers k ≥ 0, μ([k, k+1)) ≤ A[V(k + 1) + 1], where V ≥ 0 is a scalar parameter, V(k + 1) means V · (k + 1), and A does not depend on V or k. Let ρ be Schwartz with ∫ρ = 1 and S_ρ(L) = ∫ ρ(s) N(L − s) ds. Then for L ≥ 1,
  |N(L) − S_ρ(L)| ≤ C_ρ A [V(L + 1) + 1],
  where C_ρ depends only on ∫ |ρ(s)| (1 + |s|)² ds.
- **Proof.**
  - Because ∫ρ = 1, N(L) − S_ρ(L) = ∫ ρ(s)(N(L) − N(L − s)) ds.
  - By positivity, |N(L) − N(L − s)| is the μ-mass of the interval between L − s and L.
  - That interval is covered by at most ⌈|s|⌉ + 2 ≤ |s| + 3 unit windows [k, k+1), all with k ≤ L + |s| + 1. Windows with k < 0 have zero mass.
  - Hence |N(L) − N(L − s)| ≤ A(|s| + 3)[V(L + |s| + 3) + 1].
  - (filled in) For L ≥ 1, L + |s| + 3 ≤ (|s| + 3)(L + 1), so the last expression is at most A(|s| + 3)²[V(L + 1) + 1].
  - Integrate against |ρ|.
  - Atoms at endpoints are handled with half-open conventions and a one-window enlargement.
- **Sharpness / examples:** none.
- **Checks run by the report:** 12,000 exact triangle-budget cases and 1,000 discrete arithmetic cases (seed 20261103). These are examples; the second set is only an arithmetic sanity check.
- **Lean status:** Not formalized. `SteklovAudit.FixedScaleTauberian.smooth_sandwich` (SteklovAudit/FixedScaleTauberian.lean) is a related but different monotone-sandwich lemma.
- **Caveat:**
  - Reading V(k + 1) as a product with a scalar V is our interpretation. It matches the manuscript's "C(VL + 1)". If V were an arbitrary function, the stated bound would need V to be monotone with at most linear growth.
  - The hypothesis (a unit-window bound uniform in V, i.e. the analogue of (11.1)) is not established for the tetrahedron.

### R21.1 — Bounded-operator Duhamel identity with HS bound |t| ‖K‖_HS
- **Source:** run 21 report. It is the bounded-operator, opposite-orientation counterpart of R04.4.
- **Paper location:** §7.4, (7.24).
- **Statement.** Let A on H and B on G be bounded self-adjoint operators, J : H → G bounded, and K = B J − J A ∈ S₂. For every real t (with oriented integral if t < 0):
  e^{itB} J − J e^{itA} = i ∫_0^t e^{i(t−s)B} K e^{isA} ds, and ‖e^{itB} J − J e^{itA}‖_HS ≤ |t| ‖K‖_HS.
- **Proof.**
  - F(s) = e^{i(t−s)B} J e^{isA} is differentiable in operator norm, with F′(s) = −i e^{i(t−s)B} (B J − J A) e^{isA}.
  - F(t) − F(0) = J e^{itA} − e^{itB} J = ∫_0^t F′, which rearranges to the identity.
  - (filled in) For bounded A and B the integrand is norm-continuous into S₂, so the S₂-valued integral exists.
  - Unitary invariance of the HS norm and the integral triangle inequality give the bound.
- **Sharpness / examples:** none in the report.
- **Checks run by the report:** 840 randomized noncommuting real symmetric matrix cases (numerical, floating-point matrix exponential). These are examples, not a proof.
- **Lean status:** Scalar fragments only: `SteklovAudit.duhamel_discrete_budget_nonneg` and `SteklovAudit.duhamel_discrete_budget_le` (module `Section7DuhamelDefectBudget`, merged). The finite-dimensional eigenbasis analogue (orientation e^{itA}J − Je^{itB}, K = AJ − JB) is compiled as `SteklovAudit.AbstractTransfer.duhamel_hs` (SteklovAudit/AbstractTransferB2.lean). The Hilbert-space statement is not formalized.
- **Caveat:** For unbounded A and B one needs domain invariance, a differentiable intertwining relation on a core, and an HS extension of the defect; see R04.4. None of these is verified for tetrahedral operators.

### R21.2 — Weighted trace error for e^{itA} under a frame partition
- **Source:** run 21 report.

### R22.1 — A smooth multiplier whose commutator with |D| on the circle is bounded but not Hilbert–Schmidt
- **Source:** run 22 report. Generalized in R23.1.
